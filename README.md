
# Team Test

A simple JavaScript project created to practice working with Git and GitHub.

## Description

This project contains a list of team members and displays their names in the console.

## Project Structure

team-test/
├── README.md
└── app.js

## Files

- `README.md` — Project documentation.
- `app.js` — Main JavaScript file.

## How to Run

1. Install Node.js.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
node app.js
```

## Features

- Displays the team name.
- Shows a list of team members.
- Counts the total number of members.

- JavaScript
- Node.js
- Git
- GitHub
